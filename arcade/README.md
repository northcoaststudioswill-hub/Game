# North Coast Arcade

One page with a Play button for the newest build of every North Coast Studios and E Concepts game.

- **Live link (private to Will until shared):** https://claude.ai/artifact/5db3MuMYNwvJVkBTfgAKPF
- **This folder:** `index.html` is the same page as a normal web page, ready for GitHub Pages if the repo is ever
  served that way.

Games on it: Starhaven, Pocket Lantern (five cartridges), Below the Sun: First Shift, plus older builds.
To add or update a game, edit the card in `index.html` and republish the link.
