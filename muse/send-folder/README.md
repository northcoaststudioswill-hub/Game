# Pocket Lantern — the send folder

This is Will's living send folder for Pocket Lantern, set up Nov 15, 2026 at his word: a folder, not a zip, so more contents can be added later.

## How it works

- The "Send the game folder" button in The Repo Story space (Muse) sends:
  1. the current release's game file, `pocket-lantern.html`, taken from the send-this release that `LATEST.md` on `main` points at, plus
  2. **every file in this folder** — fetched live at tap time.
- So anything added here rides along automatically on the next send. No button changes needed.
- Recipients get the files as attachments (iMessage etc.), never links.

## Adding contents

Will tells Bottie in chat what to add (a note, a file, a screenshot that fits the text push, anything) and Bottie drops it in here. Text files push through the Muse GitHub app; big binaries (images, audio) live in Will's Muse files / Google Drive instead, same as the rest of the `muse/` section.

## Seeded with

- `HOW-TO-PLAY.md` — the player instructions copied from the v0.3 share package, so recipients know how to open the game.
- This README.

The frozen release zips under `v0.1/`–`v0.3/` stay untouched — this folder is the living one.
