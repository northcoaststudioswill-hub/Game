# Pocket Lantern project

| Folder | What it is |
| --- | --- |
| `games/` | Working copies, named game_version_date. Edit and test from these. |
| `backups/` | Frozen snapshots. Never edit; add new dated copies instead. |
| `handoffs/` | Notes for the next session: links, open work, revert steps. |
| `share/` | What you send to other people: the game and its how-to. The zip is ready to send. |

Current version: 2026-11-14, Version 19 on the live page.
