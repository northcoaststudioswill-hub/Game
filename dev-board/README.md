# Pocket Lantern Dev Board

A visual timeline of how the Pocket Lantern console and its cartridges were built: Sprouts, North Coast Knockout,
Rootdeep (built on Muse, then refined in Claude) and Patch & Plate.

| Copy | Where | Edit it? |
| --- | --- | --- |
| **Living board** | https://claude.ai/artifact/HyDXhUmTsQfA6SY4RhPvvJ | Yes. All new work goes here. |
| **Frozen time capsule, Nov 15 2026** | [`2026-11-15_frozen/index.html`](2026-11-15_frozen/index.html) | Never. It's a snapshot of board version 7. |

Open the frozen copy by downloading the folder and opening `index.html` in a browser. It runs offline; only the
fonts need the internet, and it falls back to system fonts without it.

## Taking another snapshot

Make a new dated folder (`dev-board/YYYY-MM-DD_frozen/`) from the living board. Don't overwrite an older snapshot.

For the repo organizer, see [`NOTE_FOR_REPO_ORGANIZER.md`](NOTE_FOR_REPO_ORGANIZER.md).
