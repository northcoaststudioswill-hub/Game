Lantern cartridges, Sproutwild, Knockout and the rest) unless the owner specifically asks for it.

The game streams them from this folder (`gotnext/music/`, next to `index.html`), shuffled, through a soft reverb that
changes with the place you are in. They are not packed into `index.html`.
