# lil Bottie game (working copy)

A copy of the Pocket Lantern main line (`alt/`, Sproutwild v9.9) made Nov 18 2026 as the starting point for a
new game centered on lil Bottie. Nothing in `alt/` or the frozen version folders is touched by work in here.

- **Play it:** `games/pocket-lantern-bottie.html`
- **Build it:** `python3 bottie/build.py` (from the repo root; music is still read from the v0.3 build, read-only)
- **Saves are separate:** every save key gets a `pl-bottie:` prefix.
- **Lore package from Will:** `lore/artist-archive.pdf` and the five reference photos in `lore/`.

Status: unchanged from `alt/` apart from the save prefix. The game concept is not picked yet.
Not copied from `alt/`: `backups/`, `playtest/` and the Sproutwild screenshots.

The Sprouts universe only appears in the Bottie game as an easter egg: a PC or console he can play the
other games on.
