# Dev photos (v0.2 and v0.2.1)

Screenshots taken by the test scripts during each development pass on Nov 14 2026, at iPhone 16 Pro Max size
(the game's 240-wide screen, shown at 2x). They're a record of how Rootdeep changed, not a manual.
Some folders were refreshed by later re-runs, so a few shots show a slightly newer build than the pass named.
Which commit each folder belongs to is in `../../CHANGELOG.md`.

| Folder | What it shows |
| --- | --- |
| `01_first_tour_after_import` | Rootdeep right after it was imported into slot 3, before the overhaul |
| `02_sprouts_style_reference` | Sprouts screens used as the visual reference for the overhaul |
| `03_knockout_moves_on_xy` | Each keeper's X, Y and super moves (taken from Knockout), keeper select |
| `04_graphics_overhaul_sprout_king` | The graphics overhaul: biomes, bosses, and the Sprout King's string, toss and bloom |
| `05_cinematics_pass` | Title, intro, boss cinematics, escape, the Sprout King's arrival, end screens |
| `06_attack_animations` | Attack frames for each weapon and keeper (frames.png collects them) |
| `07_swarm_and_interactables` | Buds swarming foes; pots, chests and other room objects |
| `08_saves_onboarding_dialogue` | Title menu, saves, Erin's intro, tips, growing dialogue, the death cinematic |
| `09_text_in_boxes_fix` | Every text box after the iPhone text-placement fix |
| `10_lantern_menu_and_burrow` | The console's Lantern menu, stats pages, the first Burrow scenes |
| `11_v0.2.1_walkups_burrow_menus` | v0.2.1: walk-ups, descent and between-chamber scenes, Hearth menu, capsule pages (`00_sheet.png` collects them) |
| `12_v0.2.1_text_audit_sheets` | A sheet of the new screens checked by the text audit |

The original playtest screenshots (01 to 11) are one folder up, with `PLAYTEST_REPORT.md`.
