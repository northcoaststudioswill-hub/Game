# The Algorithm: music video

Not built yet. This is the plan.

**The idea:** lil Bottie performs *The Algorithm* inside the Grok Fable Astra world, using the model in
`../asset/lil-bottie.js`, the song in `../songs/` and the line timings in `../lyrics/the-algorithm.timing.json`.
The game already has a boss called THE ALGORITHM, grey NPCs who repeat slogans, the Scroll Farm, the Trenches and
a command station with an empty chair, so the song has a world to walk through.
